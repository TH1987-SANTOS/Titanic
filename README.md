🛳️ Titanic – Análise e Modelo de Machine Learning

Este projeto realiza uma análise exploratória dos dados do Titanic e constrói um modelo de Machine Learning para prever a sobrevivência dos passageiros com base em atributos como sexo, idade, classe e tarifa.

📁 Estrutura do Projeto

O projeto está organizado da seguinte forma:

├── Titanic.ipynb        # Notebook principal com análise e modelo
├── requirements.txt     # Versões exatas das dependências
└── README.md            # Documentação do projeto

🎯 Objetivos do Projeto

- Realizar Análise Exploratória de Dados (EDA).

- Tratar dados faltantes, transformar variáveis e preparar o dataset.

- Treinar modelos de Machine Learning para prever a sobrevivência.

- Avaliar desempenho do modelo utilizando métricas adequadas.

- Visualizar relações e padrões relevantes nos dados.

🧠 Técnicas Utilizadas

🔍 Análise de Dados

- Inspeção inicial do dataset

- Tratamento de valores ausentes

- Codificação de variáveis categóricas

- Criação de novos atributos (se aplicado)

📊 Visualizações

- Histogramas

- Gráficos de barras

- Correlação entre variáveis

- Distribuições de sobreviventes por categoria

🤖 Machine Learning

- Divisão Treino/Teste

- Modelos utilizados (conforme seu notebook):

- LogisticRegression

- RandomForestClassifier

Métricas avaliadas:

- Acurácia

- Matriz de confusão

- Relatório de classificação

📝 Conclusão

O projeto demonstra como transformar um dataset clássico em um pipeline analítico completo, passando da exploração dos dados até a construção de modelos preditivos. Ele serve como uma base sólida para estudos iniciais em análise de dados e machine learning.
